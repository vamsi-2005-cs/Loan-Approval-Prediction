# Loan Approval Prediction — Streamlit UI

Complete Streamlit UI for the supplied Loan Approval Prediction mini project.

## Dataset
`data/train.csv` is the supplied dataset (614 rows, 13 columns).

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

Windows users can also run `run.bat`.

The app trains five classifiers directly from the included dataset and provides prediction, model performance, and dataset pages.
